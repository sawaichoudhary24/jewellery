KHUSHBU JEWELLERY - SETUP
===========================
1. Create MySQL database by importing database.sql (phpMyAdmin -> Import).
2. Confirm db.php credentials: localhost / root / empty password / jewellery_db.
3. Put the 'jewellery' folder inside XAMPP htdocs.
4. Start Apache + MySQL.
5. Open:
   Website: http://localhost/jewellery/
   Admin setup: http://localhost/jewellery/admin/create-admin.php
   Admin login: http://localhost/jewellery/admin/login.php
6. Default admin after setup:
   Email: admin@gmail.com
   Password: password
7. DELETE admin/create-admin.php after creating the admin account.
8. Product images are stored in uploads/products/.
